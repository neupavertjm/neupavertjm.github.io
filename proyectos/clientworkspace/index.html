ClientWorkspace (Puesto de mando documental)(Document operations workspace)

Orquesta el digitalizador OCR y RagDesk en un único flujo por cliente, sin mezclar nunca documentos ni índices entre ellos.

Orchestrates the OCR digitizer and RagDesk into a single per-client flow, never mixing documents or indexes between them.

Qué hace

What it does

Organiza el trabajo documental de varios clientes a la vez sin que sus archivos, bases de datos o índices se mezclen nunca entre sí: cada cliente y cada proyecto tiene su propia carpeta aislada, con su propia base de datos SQLite.

Al importar documentos calcula el hash de cada archivo para detectar duplicados exactos antes de procesarlos dos veces, y deja los originales intactos — todo el procesamiento posterior trabaja sobre copias.

El OCR y la extracción de metadatos (fechas, referencias, con un nivel de confianza explícito) se ejecutan como trabajos en segundo plano con seguimiento de progreso, y cada documento procesado queda automáticamente indexado para búsqueda de texto completo.

Para consulta documental privada, puede dar de alta una instancia de RagDesk propia y aislada para cada cliente — el índice de cada proyecto vive dentro de su propia carpeta, nunca compartido entre clientes.

It organizes the document work of several clients at once without their files, databases or indexes ever mixing: each client and each project gets its own isolated folder, with its own SQLite database.

When importing documents it hashes each file to detect exact duplicates before processing them twice, and leaves the originals untouched — all later processing works on copies.

OCR and metadata extraction (dates, references, with an explicit confidence level) run as background jobs with progress tracking, and every processed document is automatically indexed for full-text search.

For private document Q&A, it can spin up its own isolated RagDesk instance per client — each project's index lives inside its own folder, never shared between clients.

Related services
